# Quality Quantifier Monitoring

**Quality Quantifier Monitoring** — это Telegram Mini App для мониторинга доступности ваших сервисов. Бот позволяет добавлять ресурсы, отслеживать их статус в реальном времени и получать уведомления о сбоях. Поддерживается несколько типов проверок, гибкие настройки и публичные страницы для общего доступа.

## ✨ Возможности

- **Типы проверок:**
  - `HTTP(s)` – проверка доступности веб-сайта или API.
  - `HTTP(s) с ключевым словом` – поиск заданного слова в HTML, CSS и JS.
  - `TCP порт` – проверка открытости порта.
  - `DNS` – проверка резолвинга домена.

- **Гибкая настройка каждого ресурса:**
  - Частота опроса: от 1 минуты до 3 часов.
  - Повторная проверка при неудаче (0–3 раза).
  - Допустимые HTTP‑коды (диапазоны или конкретные).
  - Уведомления в Telegram при падении и восстановлении.

- **Статистика аптайма:**
  - Количество проверок за 24 часа и месяц.
  - Процент доступности (uptime) за эти периоды.

- **Публичные страницы:**
  - Создание общедоступной ссылки для любого ресурса.
  - Настройка видимости: заголовок, описание, скрытие отдельных параметров.
  - Включение/выключение страницы и удаление.
